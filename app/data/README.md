# Demo data

Small files derived from the Bank Account Fraud (BAF) dataset suite, base variant, by Feedzai
(NeurIPS 2022): model scores and decisions for the test months, plus 300 example applications.

data. Non-commercial use only, with attribution; adaptations must keep this licence.

Source: https://github.com/feedzai/bank-account-fraud

Jesus, S., Pombal, J., Alves, D., Cruz, A., Saleiro, P., Ribeiro, R. P., Gama, J., and Bizarro, P.
(2022). Turning the Tables: Biased, Imbalanced, Dynamic Tabular Datasets for ML Evaluation.
NeurIPS 2022.

Regenerate with `make demo-data` after training.
